# 人工智能创作与机器感知互动实验室

山东教育出版社《人工智能通识·第一册》配套离线互动网页工具。

## 使用

打开 [`index.html`](./index.html) 进入总目录，或查看 [`使用说明.md`](./使用说明.md)。

- 10 节独立 HTML 实验室（`labs/`）
- 完全离线：无 CDN、无联网 API
- 本机保存 / 导出 / 导入项目
- 不采集真实人脸与隐私数据
