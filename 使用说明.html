使用说明

山东教育出版社《人工智能通识·第一册》配套离线互动工具

快速开始

  1. 用浏览器打开根目录 index.html（推荐 Chrome / Edge / Safari）。
  2. 按单元进入对应课时，或直接打开 labs/ 下各 HTML 文件。
  3. 无需安装、无需联网、无需账号。

每节通用操作

  • 保存 / 导出 / 导入：进度保存在本机浏览器，可导出 JSON 备份。
  • 恢复示例 / 清除数据：回到教材示例或清空本机保存。
  • 全屏：适合教室大屏演示。
  • 重置：清空当前实验状态。

单元项目

第一单元 · AI 传统文化创作展：调查身边 AI → 文本提示词 → 视觉创作 → 配乐 → 文化宣传短片。

第二单元 · 校园智能识别体验中心：人脸应用 → 特征匹配与隐私 → OCR → 动植物百科 → 智能垃圾分类。

安全与伦理

  • 生成与识别均为离线规则模拟，结果可能错误，必须人工核验。
  • 人脸相关页面仅使用虚拟头像 / 卡通脸 / 合成特征。
  • 车牌、身份等示例均为虚构数据。
  • 不要求填写姓名、电话、住址等隐私信息；数据不上传网络。
音乐课若无声音：请先点击页面任意按钮后再播放（浏览器自动播放策略）。重要成果请同时导出 JSON 备份。
